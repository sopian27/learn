# Course Roadmap

## Course Information

* Course Name: Football Tactical Analysis — dari Penonton Biasa sampai Membaca Taktik Setara Analyst
* Category: Football Tactical Analysis (Domain: football-tactics — lihat `domains/football-tactics/DOMAIN.md`)
* Difficulty: Level 0 (penonton biasa, hanya bisa bilang "mainnya bagus"/"jelek" tanpa bisa jelaskan kenapa) → Level 4 (mampu membedah struktur taktik pertandingan, mendiagnosis sistem-vs-eksekusi, dan menyusun kritik taktik terstruktur setara analyst/coach)
* Estimated Duration: 9 modul, 4 lesson/modul (36 lesson), pace mengikuti Applied Practice nyata (Match Tactical Report butuh benar-benar menganalisis pertandingan konkret per modul, bukan latihan hipotetis) — realistis, bukan dikebut
* Prerequisites: Tidak ada prasyarat teknis. Kesediaan menganalisis pertandingan secara aktif (dengan catatan terstruktur, bukan sekadar nonton pasif) dan menulis Match Tactical Report secara jujur setiap modul, sesuai `domains/football-tactics/DOMAIN.md` bagian "Applied Practice Definition".
* Kalibrasi user (2026-08-09): mode analisis memakai **pertandingan terkenal yang sudah terdokumentasi luas** (bukan nonton live bareng — mentor tidak bisa menonton video real-time); anchor liga **Premier League**; scope eksplisit TIDAK mencakup bermain bola/coaching drill, FIFA/eFootball, fantasy football, dan judi/taruhan bola.

# Learning Objectives

* [ ] Membedakan reaksi penonton ("mainnya jelek") dari kritik taktik (argumen dengan bukti + mekanisme), dan memahami bedanya formasi di atas kertas vs bentuk permainan aktual
* [ ] Memetakan peran taktik tiap pemain dalam sistem (bukan sekadar posisi/nomor punggung)
* [ ] Menganalisis struktur menyerang — build-up, progression, chance creation — dan pola yang menciptakan peluang
* [ ] Menganalisis struktur bertahan — defensive shape, pressing trigger, transisi — dan pola yang mematikan serangan lawan
* [ ] Membaca perubahan taktik selama pertandingan (substitusi, perubahan formasi, momentum) secara real-time dari deskripsi pertandingan
* [ ] Mendiagnosis dengan tepat: kegagalan/keberhasilan berasal dari sistem atau eksekusi, taktik atau eksekusi — skill inti domain ini
* [ ] Menyusun profil taktik satu tim (kekuatan, kelemahan, ketergantungan pemain kunci) dan membandingkannya lintas pertandingan
* [ ] Menulis Match Tactical Report terstruktur (bukti spesifik, diagnosis eksplisit, saran perbaikan realistis) sebagai Capstone Project berkualitas portofolio

# Course Modules

## Module 1 — Fondasi: Formasi vs Sistem, Reaksi Penonton vs Analisis Taktik

Description: Sebelum masuk teknis, pahami dulu apa yang membedakan reaksi penonton dari analisis taktik berargumen, dan kenapa formasi di atas kertas seringkali tidak sama dengan bentuk permainan sesungguhnya di lapangan.

Lessons:

* [ ] 1.1 Reaksi vs kritik taktik — apa yang membuat "mainnya jelek" menjadi argumen yang bisa dipertanggungjawabkan
* [ ] 1.2 Formasi di atas kertas vs shape aktual — in-possession shape vs out-of-possession shape
* [ ] 1.3 Anatomi lapangan — thirds, half-spaces, channels, dan kenapa posisi di zona itu penting
* [ ] 1.4 Empat fase permainan — build-up, progression, chance creation, defending — plus transisi di antaranya

Mini Project: Pilih satu pertandingan Premier League terkenal, identifikasi formasi on-paper vs shape aktual yang teramati dari match report/highlight yang sudah terdokumentasi luas.

Status: Not started

---

## Module 2 — Peran Pemain dalam Sistem

Description: Posisi bukan peran — modul ini membedah tugas taktik konkret tiap posisi di lapangan modern, dari lini belakang sampai lini depan.

Lessons:

* [ ] 2.1 Posisi vs peran (positional role) — kenapa nomor punggung tidak menentukan tugas
* [ ] 2.2 Peran lini belakang — ball-playing centre-back, fullback vs wingback, inverted fullback
* [ ] 2.3 Peran lini tengah — pivot/regista, box-to-box, mezzala, #10
* [ ] 2.4 Peran lini depan — target man, false 9, inside forward, winger klasik vs inverted winger

Mini Project: Petakan peran taktik (bukan cuma posisi) tiap pemain dari satu starting XI pertandingan Premier League terkenal.

Status: Not started

---

## Module 3 — Membangun Serangan (Attacking Structure)

Description: Bagaimana tim menciptakan peluang secara terstruktur — dari build-up di lini belakang sampai pola yang berujung ke gol.

Lessons:

* [ ] 3.1 Build-up dari belakang — struktur relatif (mis. 2-3-5), overload & underload
* [ ] 3.2 Progression — switching play, playing through lines vs around lines, third-man run
* [ ] 3.3 Chance creation — overload half-space, underlap/overlap, box occupancy pattern
* [ ] 3.4 Finishing pattern & set-piece attacking dasar

Mini Project: Bedah satu build-up sequence/gol terkenal — jelaskan pola konkret yang menciptakannya, bukan hanya deskripsi hasil akhir.

Status: Not started

---

## Module 4 — Bertahan (Defensive Structure)

Description: Sisi lain dari koin — bagaimana tim terstruktur untuk mencegah dan mematikan serangan lawan.

Lessons:

* [ ] 4.1 Defensive shape — block tinggi/mid/rendah, compactness
* [ ] 4.2 Pressing — pressing trigger, counter-press (gegenpressing), man-oriented vs zonal pressing
* [ ] 4.3 Transisi bertahan — rest defense, counter-attack defending
* [ ] 4.4 Set-piece defending dasar

Mini Project: Bedah satu sequence pressing/turnover terkenal — jelaskan trigger dan struktur pressing di baliknya.

Status: Not started

---

## Module 5 — Membaca Perubahan Taktik Selama Pertandingan

Description: Taktik tidak statis 90 menit — modul ini melatih membaca sinyal perubahan taktik saat pertandingan berjalan.

Lessons:

* [ ] 5.1 Membaca substitusi sebagai sinyal taktik, bukan sekadar rotasi
* [ ] 5.2 Perubahan formasi in-game dan tujuannya (mengejar hasil vs mengunci hasil)
* [ ] 5.3 Momentum shift dan manajemen game state (bermain dengan skor unggul/tertinggal/seri)
* [ ] 5.4 Duel taktik pelatih vs pelatih — in-game adjustment sebagai catur taktik

Mini Project: Bedah satu pertandingan Premier League terkenal dengan perubahan taktik signifikan di babak kedua — jelaskan apa yang berubah dan kenapa.

Status: Not started

---

## Module 6 — Diagnosis: Pemain vs Sistem, Taktik vs Eksekusi

Description: Modul inti sesuai tujuan utama learner — kerangka eksplisit untuk memisahkan kegagalan yang berasal dari desain taktik (sistem) dari kegagalan yang berasal dari individu (eksekusi), dan taktik yang salah dari taktik yang benar tapi gagal dijalankan.

Lessons:

* [ ] 6.1 Kerangka diagnosis — pertanyaan sistematis untuk memisahkan sistem vs eksekusi sebelum menyimpulkan
* [ ] 6.2 Pola kegagalan sistem umum — mismatch personel vs sistem, structural overload oleh lawan
* [ ] 6.3 Pola kegagalan eksekusi umum — individual error, fatigue, breakdown komunikasi
* [ ] 6.4 Studi kasus — pertandingan terdokumentasi luas dengan diagnosis publik yang keliru (blame pemain padahal sistem, atau sebaliknya)

Mini Project: Pilih satu pertandingan Premier League terkenal di mana satu tim bermain buruk/kalah — buat diagnosis tertulis eksplisit (sistem atau eksekusi, taktik atau eksekusi) dengan bukti konkret.

Status: Not started

---

## Module 7 — Kekuatan & Kelemahan Tim, Profil Taktik Klub

Description: Naik satu level dari satu pertandingan ke identitas taktik satu tim secara keseluruhan, dan bagaimana dua gaya berbeda saling beradu.

Lessons:

* [ ] 7.1 Menyusun team tactical profile — identitas menyerang, identitas bertahan, ketergantungan pemain kunci
* [ ] 7.2 Head-to-head — bagaimana dua tim dengan gaya kontras saling mematikan
* [ ] 7.3 Filosofi pelatih — studi kasus perbandingan (Guardiola, Arteta, era Klopp, Sacchi sebagai akar historis)
* [ ] 7.4 Mengenali evolusi identitas taktik tim sepanjang musim/di bawah pelatih yang sama

Intermediate Project: Analisis komparatif 2-3 pertandingan Premier League — dari tim yang sama (identitas taktik konsisten/berubah) ATAU duel dua gaya kontras — menggabungkan lensa Module 1-6.

Status: Not started

---

## Module 8 — Menyusun Kritik & Saran yang Tajam tapi Masuk Akal

Description: Menutup gap antara "bisa mendiagnosis" dan "bisa menyampaikan penilaian secara meyakinkan" — termasuk kewajiban memahami intent pelatih dulu sebelum menghakimi, dan menyusun saran perbaikan yang realistis.

Lessons:

* [ ] 8.1 Struktur kritik taktik — klaim, bukti (menit/zona/pemain), mekanisme, saran perbaikan
* [ ] 8.2 Intent check — memahami apa yang coba dicapai pelatih sebelum mengevaluasi (hasil ≠ otomatis bukti taktik salah)
* [ ] 8.3 Menulis saran perbaikan realistis — solusi taktik konkret, bukan "ganti pelatih"/"jual pemain"
* [ ] 8.4 Empat lensa practitioner reference frame — memilih gaya penyampaian sesuai audiens

Mini Project: Tulis Match Tactical Report lengkap untuk satu pertandingan, direview memakai Review Style domain (`domains/football-tactics/DOMAIN.md`).

Status: Not started

## Module 9 — Capstone: Match Tactical Report Kualitas Portofolio

Description: Mengintegrasikan seluruh lensa Module 1-8 jadi satu Match Tactical Report penuh untuk satu pertandingan besar/bersejarah, disimpan sebagai artifact portofolio.

Lessons:

* [ ] 9.1 Pemilihan pertandingan capstone dan alasan memilihnya
* [ ] 9.2 Riset mendalam lintas sumber (match report, data statistik, wawancara/press conference pelatih)
* [ ] 9.3 Penyusunan draft Match Tactical Report penuh (shape, menyerang, bertahan, momen taktik kunci, diagnosis sistem-vs-eksekusi, verdict)
* [ ] 9.4 Revisi berdasarkan review dan finalisasi ke `portofolio/`

Capstone Project: Match Tactical Report kualitas portofolio untuk satu pertandingan Premier League besar/bersejarah, mengintegrasikan seluruh lensa taktik jadi satu argumen kritik koheren dengan diagnosis sistem-vs-eksekusi eksplisit. Review memakai `domains/football-tactics/DOMAIN.md` bagian "Review Style" (Evidence Specificity, System-vs-Execution Diagnosis Accuracy, Terminology Accuracy, Intent Check) di atas Universal Review Rubric (`ai-los/CORE_LOS.md`).

Status: Not started

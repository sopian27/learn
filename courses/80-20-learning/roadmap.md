# Catatan Scope

1. **Pembeda dari `courses/learning-science`**: course itu tentang *motivasi, flow, dan kebiasaan* (membuat belajar menyenangkan). Course ini tentang *strategi seleksi dan efektivitas* (memilih apa yang dipelajari, cara menguji pemahaman, kapan berhenti). Keduanya saling melengkapi; tidak menduplikasi isi. Cross-reference ke learning-science untuk motivasi/flow, bukan diajarkan ulang di sini.
2. **Pembeda dari `courses/critical-thinking` dan `courses/brain-mastery`**: keduanya tentang kualitas berpikir/otak umum. Course ini khusus *proses belajar* (input → kemampuan).
3. **Klaim riset**: sumber user memuat klaim sains belajar (active recall, spaced repetition, desirable difficulty, interleaving, Feynman). Saat generate lesson, klaim itu diverifikasi ke riset primer (mis. Roediger & Karpicke, Cepeda, Bjork), tidak diterima mentah. Pareto 80/20 diajarkan sebagai *cara berpikir distribusi dampak*, bukan hukum angka tepat (sesuai bagian 0 dan 65 sumber).
4. **Applied Practice bersifat opsional** — tidak pernah menjadi syarat menutup lesson.

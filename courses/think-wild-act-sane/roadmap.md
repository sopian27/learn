# Course Roadmap

## Course Information

* Course Name: Think Wild, Act Sane — Insanity Thinking: Berpikir Gila, Bertindak Waras
* Category: Berpikir Divergen/Generatif & Eksperimen Kecil-Berisiko-Terukur (Domain: insanity-thinking — lihat `domains/insanity-thinking/DOMAIN.md`)
* Basis: dokumen "INSANITY — Berpikir Gila, Bertindak Waras" buatan/dikumpulkan user (25 Part bernomor, 30-Day Insanity Challenge, Insanity Lab notebook, 10 Insane Questions, Final Framework 8 langkah). ±1/3 outline **tidak dipindahkan** karena identik dengan modul domain lain yang sudah ada (lihat "Catatan Scope"); sisanya dilipat jadi 11 modul.
* Difficulty: Level 0 (solusi pertama yang terpikir langsung dieksekusi; kebingungan dirasakan sebagai bukti kebodohan; kegagalan dirasakan sebagai identitas; "begitu dari dulu" cukup jadi alasan) → Level 3 (bisa menghasilkan 20 ide liar sebelum menilai satupun, membongkar pola lewat input baru, mendiagnosis kebingungan sebagai model mental belum lengkap, menjalankan Experiment Loop dengan risiko terukur, memakai reframing 10x/zero-based/subtraction, dan menjalankan Insanity Filter sebelum eksperimen berisiko)
* Level: Beginner → Intermediate
* Estimated Duration: 11 modul, 3-4 lesson/modul (±38 lesson) + 30-Day Insanity Challenge (paralel) + Capstone. Pace mengikuti kedalaman refleksi, bukan dikebut.
* Prerequisites: Tidak ada prasyarat teknis. Course ini **mengasumsikan** learner sudah/sedang menempuh `critical-thinking` (Module 3-4, 6, 8) untuk five whys/first principles/inversion/steelmanning — tidak diulang di sini. Tidak wajib selesai duluan, tapi lesson di sini akan merujuk ke situ.

# Course Modules

## Module 1 — Batas Domain: Insanity Sebagai Metafora, Bukan Izin (ditambahkan)

Description: Sebelum menghasilkan satu ide liar pun, kuasai batasnya — apa yang course ini ajarkan dan apa yang sudah diajarkan lebih dalam di domain lain. Safety framing ditaruh di depan, bukan di akhir.

Lessons:

* [ ] 1.1 "Insanity" sebagai metafora keberanian mempertanyakan vs irasionalitas berbahaya — dua definisi dipisahkan tegas; bukan alat diagnosis kesehatan mental
* [ ] 1.2 Peta overlap — apa yang TIDAK diajarkan di sini (five whys/first principles/inversion/steelmanning → `critical-thinking`; identitas/keberanian sosial → `courage-to-try`, `character-development`; deep work → `work-management`; mekanika bisnis → `entrepreneurship`) dan kenapa
* [ ] 1.3 Think Wild, Act Sane — kontrak course: ide boleh ekstrem, eksekusi diukur, realitas tetap jadi hakim
* [ ] 1.4 Format Insanity Lab — struktur entri (Experiment/Why/Hypothesis/Small Test/Result/Lesson/Next) yang dipakai di semua modul berikutnya

Mini Project: Tulis satu paragraf "kontrak pribadi" — apa yang membuatmu berhenti kalau eksperimen mulai berisiko, sebelum modul lain dimulai.

## Module 2 — The Crazy Idea Machine: Kuantitas Sebelum Kualitas

Description: Untuk menemukan ide bagus, hasilkan juga ide buruk lebih dulu. Berbasis Osborn (*Applied Imagination*, 1953) — deferral of judgment, kuantitas melahirkan kualitas.

Lessons:

* [ ] 2.1 Kenapa ide ke-1 sampai ke-5 biasanya pola familiar, dan ide ke-15 ke atas mulai membuka perspektif baru — dasar riset Osborn, dicek ulang tahun dan klaim intinya
* [ ] 2.2 Aturan sesi: tunda penilaian, kuantitas dulu, kombinasikan/lompat dari ide orang lain, semua ide dicatat termasuk yang "buruk"
* [ ] 2.3 Generate Bad Ideas — teknik sengaja menulis ide buruk untuk menghancurkan pola pikir otomatis, sebelum menyaring
* [ ] 2.4 Kapan sesi ini berhenti — antara "belum cukup liar" dan "sudah waktunya menilai" (rujukan `critical-thinking` untuk fase penilaian)

Mini Project: Sesi brainstorming 20 ide untuk satu masalah nyata (kerja/belajar/personal), termasuk minimal 5 ide yang sengaja "buruk", tanpa menilai satupun sampai daftar selesai.

Status: Not started

## Module 3 — Break the Pattern & The Polymath Effect

Description: Otak menyukai pola karena hemat energi, tapi pola lama menghasilkan hasil lama. Dua cara membongkarnya: mengubah input/lingkungan, dan menyambungkan pengetahuan lintas disiplin.

Lessons:

* [ ] 3.1 Pattern interruption — kenapa urutan otomatis (belajar → baca → catat → lupa) perlu diselingi urutan baru (pertanyaan → recall → jelaskan → eksperimen)
* [ ] 3.2 Change the environment — mengubah input (bidang lain, orang berbeda, sejarah, seni, filsafat) untuk memicu unexpected connections; batas: bukan sekadar "jalan-jalan", tapi input yang sengaja dipilih beda
* [ ] 3.3 The Polymath Effect — riset Epstein (*Range*, 2019) tentang generalis vs spesialis, dicek berimbang dengan kritik pro-spesialisasi (deliberate practice, Ericsson) supaya tidak sepihak
* [ ] 3.4 Connection Journal — format harian "hari ini saya belajar X → X berhubungan dengan apa yang sudah saya tahu?"; contoh rantai domain software engineering (mis. ETag → versioning → optimistic concurrency)

Mini Project: Connection Journal 7 hari — satu entri per hari, minimal satu koneksi lintas disiplin yang genuinely baru (bukan koneksi yang sudah jelas).

Status: Not started

## Module 4 — Embrace Confusion: The Confusion Protocol

Description: Kebingungan sering diterjemahkan otak jadi "saya bodoh". Ganti jadi "model mental saya belum lengkap" — beda dari `learning-science` yang bicara motivasi/habit belajar, ini soal mendiagnosis KEBINGUNGAN itu sendiri.

Lessons:

* [ ] 4.1 Kenapa "saya tidak mengerti" ≠ "saya bodoh" — ringkas growth mindset (Dweck), pendalaman penuh di `character-development`
* [ ] 4.2 Confusion Protocol — 7 langkah: berhenti, tulis apa tepatnya tidak dipahami, pisahkan vocabulary/concept/relationship/example/mechanism, cari contoh sederhana, jelaskan dengan kata sendiri, coba, cari kesalahan
* [ ] 4.3 Memisahkan lima jenis kebingungan — istilah asing (vocabulary) vs konsep belum jelas (concept) vs hubungan antar-bagian tidak terlihat (relationship) vs kurang contoh (example) vs tidak tahu cara kerjanya (mechanism); masing-masing butuh strategi beda
* [ ] 4.4 Kapan kebingungan adalah sinyal berhenti sebentar vs sinyal lanjut mencoba — bukan aturan kaku, latihan kalibrasi

Mini Project: Ambil satu topik yang sedang membingungkan (dari course aktif manapun), jalankan Confusion Protocol lengkap 7 langkah, tulis hasil "apa yang berubah setelah dipisah".

Status: Not started

## Module 5 — Failure Is Data: The Experiment Loop

Description: Gagal bukan identitas — yang gagal adalah hipotesis. Berbasis Build-Measure-Learn (Ries, *The Lean Startup*, 2011), dipakai generik untuk eksperimen personal, bukan mekanika bisnis (itu `entrepreneurship`).

Lessons:

* [ ] 5.1 Gagal ≠ identitas — mental model scientist: yang gagal adalah hipotesis, bukan "saya sebagai manusia"
* [ ] 5.2 Experiment Loop — Hypothesis → Experiment → Result → Analysis → Adjustment → Experiment (versus pola umum Idea → Emotion → Action → Hope)
* [ ] 5.3 Fail Cheap — mengecilkan taruhan sebelum tahu hasilnya (waktu, uang, cakupan dibatasi eksplisit); rujukan singkat budaya prototyping IDEO untuk versi desain, `entrepreneurship` untuk versi bisnis
* [ ] 5.4 Menulis entri Insanity Lab dari hasil gagal — kenapa "Lesson" wajib diisi meski "Result" negatif

Mini Project: Satu Experiment Loop nyata (bukan simulasi) pada masalah kecil, dengan hipotesis tertulis SEBELUM eksperimen dijalankan, dan entri Insanity Lab lengkap setelahnya — apapun hasilnya.

Status: Not started

## Module 6 — Extreme Reframing: 10x, Zero-Based, Subtraction

Description: Tiga pertanyaan yang memaksa keluar dari solusi tambal-sulam dengan mengubah skala target atau titik acuan berpikir.

Lessons:

* [ ] 6.1 The 10x Question — target ekstrem (bukan "20% lebih baik", tapi "10x lebih baik") memaksa solusi berbeda, bukan optimasi inkremental; rujukan moonshot X/Astro Teller, dicek dari sumber primer; contoh performance-engineering (latency turun 10x vs 20%)
* [ ] 6.2 Zero-Based Thinking — "kalau ini belum pernah dibuat, apakah kita akan membuatnya dengan cara yang sama?"; dipakai untuk legacy system, proses, kebiasaan pribadi; istilah dicek atribusinya (Brian Tracy vs generik) sebelum dipakai bernama
* [ ] 6.3 The Subtraction Principle — berbasis riset Klotz (*Subtract*, 2021; studi "people systematically overlook subtractive changes", *Nature* 2021) — inovasi lewat menghapus, bukan hanya menambah; contoh: hapus service/dependency/meeting/fitur
* [ ] 6.4 Memilih reframing yang tepat — kapan 10x, kapan zero-based, kapan subtraction paling relevan untuk satu masalah; latihan memakai ketiganya pada masalah yang sama untuk membandingkan hasil

Mini Project: Satu masalah nyata (teknis atau personal) direframe tiga kali — lewat 10x Question, Zero-Based Thinking, dan Subtraction Principle — bandingkan solusi yang muncul dari masing-masing.

Status: Not started

## Module 7 — Disciplined Insanity: Tiga Lapis & Insanity Filter

Description: Ide ekstrem tanpa disiplin adalah chaos; dengan disiplin adalah inovasi. Kerangka penggabung semua modul sebelumnya sebelum eksekusi nyata.

Lessons:

* [ ] 7.1 Tiga lapis — Imagination (bebas, Module 2-3), Validation (data/eksperimen/logika, Module 4-6), Execution (risk management/timeline/budget/safety)
* [ ] 7.2 The Insanity Filter — 8 pertanyaan wajib sebelum tindakan ekstrem: tujuan, asumsi, bukti, risiko terbesar, worst-case, skala kecil, ukuran keberhasilan, kapan berhenti
* [ ] 7.3 Kriteria Berhenti — ditulis SEBELUM eksekusi, bukan sesudah; contoh format singkat
* [ ] 7.4 Kapan sebuah ide "belum lolos filter" — tanda ide masih perlu divalidasi lebih jauh, bukan langsung dieksekusi

Mini Project: Ambil satu ide dari Module 2/6 yang paling menjanjikan tapi berisiko menengah-tinggi, jalankan Insanity Filter 8 pertanyaan lengkap, tulis Kriteria Berhenti sebelum (bukan sesudah) bertindak.

Status: Not started

## Module 8 — The Dark Side & Golden Rule

Description: Berpikir berbeda tidak otomatis membuat seseorang benar. Modul ini checklist aktif sebelum capstone, bukan disclaimer penutup yang dilupakan.

Lessons:

* [ ] 8.1 Lima bahaya — ego ("saya berbeda berarti lebih pintar"), confirmation bias (hanya cari bukti pendukung), recklessness (berani tanpa menghitung risiko), obsession tanpa recovery, delusion (yakin tanpa bukti); masing-masing dicek pada rencana eksperimen sendiri
* [ ] 8.2 Insanity vs Madness — metafora keberanian mempertanyakan vs irasionalitas berbahaya (kehilangan kontak realitas, mengabaikan konsekuensi serius); batas eksplisit, tidak dipakai untuk diagnosis diri/orang lain
* [ ] 8.3 The Golden Rule — ide boleh ekstrem, eksperimen boleh berani, tapi realitas tetap hakim; kapan data bilang salah (ubah), eksperimen gagal (belajar), risiko terlalu besar (kecilkan), kesehatan terganggu (berhenti)
* [ ] 8.4 Audit balik — untuk satu eksperimen yang direncanakan (Module 5-7), jawab kelima pertanyaan Dark Side secara tertulis sebelum lanjut ke Capstone

Mini Project: Dark Side Audit — tulis jawaban lima pertanyaan bahaya untuk eksperimen paling berisiko yang sudah direncanakan di modul sebelumnya; revisi rencana bila audit menemukan tanda bahaya.

## Module 9 — Think Like an Inventor: The Problem Notebook

Description: Inventor tidak bertanya "apa yang ingin saya buat", tapi "apa yang membuat orang kesulitan". Mencatat masalah sehari-hari sebagai bahan proyek, bukan keluhan pasif.

Lessons:

* [ ] 9.1 Observe problems, bukan cuma ide — pergeseran dari "apa yang saya inginkan" ke "kesulitan apa yang saya lihat"
* [ ] 9.2 Problem Notebook — format harian "hari ini saya menemukan masalah..." lalu "bagaimana kalau...?"; contoh lintas konteks (build lambat, dokumentasi buruk, belajar tapi lupa)
* [ ] 9.3 Dari catatan ke proyek — bagaimana kumpulan problem notebook (bahkan mingguan) jadi sumber ide proyek/eksperimen nyata, bukan arsip keluhan; rujukan ringkas `entrepreneurship` untuk problem discovery versi bisnis
* [ ] 9.4 Menyaring notebook — bukan semua masalah layak jadi proyek; kriteria singkat (frekuensi, dampak, dalam kendali)

Mini Project: Problem Notebook 7 hari, minimal 1 masalah dicatat per hari; pilih satu untuk dilanjutkan sebagai eksperimen di Module 10-11.

# 30-Day Insanity Challenge (paralel)

Dijalankan paralel sepanjang course. Hari/minggu terlewat dicatat sebagai terlewat, bukan disembunyikan.

* **Week 1 — Generate & Filter:** 20 ide liar untuk satu masalah nyata → saring lewat Insanity Filter → pilih satu. (Modul 2, 7)
* **Week 2 — Break One Pattern:** ubah satu kebiasaan/input secara sengaja; catat koneksi baru yang muncul. (Modul 3)

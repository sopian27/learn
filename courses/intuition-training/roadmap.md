# Course Roadmap

## Course Information

* Course Name: Intuition Training & Calibrated Judgment — dari 0 sampai Expert
* Category: Melatih Intuisi — Observasi, Pattern Recognition, Prediksi, Membaca Situasi Sosial, Membedakan Intuisi vs Anxiety, Decision-Making, dan Evaluasi Feedback (Domain: intuition-training — lihat `domains/intuition-training/DOMAIN.md`)
* Difficulty: Level 0 (mengandalkan firasat tak terverifikasi, tidak bisa membedakan gut-feeling dari cemas, tidak pernah mengecek akurasi prediksi sendiri) → Level 4 (observasi terstruktur, pattern library terbangun dari pengalaman nyata, prediksi terkalibrasi dengan skor terukur, membaca situasi sosial berbasis sinyal terverifikasi, decision-making cepat teruji, dan feedback loop pribadi berjalan berkelanjutan)
* Estimated Duration: 10 modul, 4 lesson/modul (40 lesson) — pace mengikuti kemunculan situasi nyata (untuk Observation/Prediction/Social Read/Discrimination/Decision Log), jadi realistis bukan dikebut
* Prerequisites: Tidak ada prasyarat teknis. Kesediaan mencatat log nyata tiap modul (bukan hipotetis) dan menunggu hasil sungguhan sebelum menilai prediksi — sesuai `domains/intuition-training/DOMAIN.md` bagian "Applied Practice Definition". Skenario studi kasus hanya jembatan sementara bila situasi nyata belum muncul di modul awal. Learner memilih satu domain nyata (kerja/hobi/relasi) sejak Module 1 untuk membangun pattern library sepanjang course.

---

# Catatan Scope (asumsi kalibrasi, dikonfirmasi saat approval)

* **Bukan mistisisme.** Course ini berbasis riset Naturalistic Decision Making (Klein), riset kalibrasi (Tetlock), dan neurosains interoception (Damasio, Garfinkel & Critchley) — bukan firasat/energi/ESP. Setiap klaim intuisi wajib dilacak ke pattern nyata + feedback terverifikasi.
* **"Intuisi vs anxiety" bukan berarti anxiety selalu salah.** Module 4 melatih diskriminasi, bukan dismissal — ancaman genuine tetap divalidasi. Kalau log menunjukkan anxiety kronis, diarahkan ke `emotional-resilience` (course itu yang menangani regulasi), bukan diselesaikan lewat course ini.
* **Domain latihan pribadi.** Learner disarankan memilih satu domain nyata (mis. membaca kode, negosiasi kerja, olahraga, hobi tertentu) di Module 1 sebagai tempat membangun pattern library sepanjang course — supaya feedback loop-nya konsisten, bukan tersebar ke banyak domain sekaligus.

Ketiga asumsi di atas menunggu konfirmasi/koreksi user saat approval roadmap, sebelum Lesson 1 dimulai.

# Learning Objectives

* [ ] Memahami intuisi sebagai pattern recognition terlatih (Simon, Chase & Simon, Klein) — bukan bakat mistis
* [ ] Melakukan observasi terstruktur yang menangkap detail yang biasanya terlewat (mengatasi inattentional blindness)
* [ ] Membangun pattern library dari pengalaman nyata berulang di satu domain pilihan, tanpa jatuh ke pareidolia/overfitting
* [ ] Membedakan sinyal intuisi (pattern-based, spesifik) dari sinyal anxiety (difus, katastrofik) berdasarkan kriteria fisiologis (Damasio, interoception)
* [ ] Membaca situasi sosial lewat sinyal nonverbal terverifikasi (FACS — Ekman) dan dinamika grup, bukan proyeksi/tebakan
* [ ] Membuat prediksi eksplisit dengan confidence level yang terkalibrasi akurat (metodologi superforecaster — Tetlock)
* [ ] Mengetahui kapan lingkungan cukup "kind" untuk dipercaya intuisinya dan kapan wajib beralih ke reasoning deliberatif (Hogarth, Kahneman-Klein)
* [ ] Membuat keputusan cepat di bawah tekanan lewat model Recognition-Primed Decision (Klein)
* [ ] Memakai fast-and-frugal heuristics (Gigerenzer) secara sadar syaratnya, bukan sembarangan
* [ ] Mengevaluasi feedback secara aktif dan menghindari resulting bias (Annie Duke) saat menilai kualitas keputusan
* [ ] Menyusun dan menjalankan Personal Intuition Calibration System yang teruji lewat track record nyata

# Course Modules

## Module 1 — Foundations: Intuisi sebagai Recognition, Bukan Sihir

Description: Sebelum masuk teknik, bongkar dulu mitos "intuisi = bakat mistis". Intuisi didefinisikan sebagai pattern recognition yang dibangun dari pengalaman berulang (Simon, Chase & Simon), dipelajari lewat riset Naturalistic Decision Making pada expert nyata (Klein), dan diperingatkan sejak awal: tidak semua intuisi layak dipercaya (kind vs wicked environment — Hogarth).

Lessons:

* [ ] 1.1 Definisi intuisi: "nothing more and nothing less than recognition" (Herbert Simon) — riset chunking Chase & Simon pada pemain catur
* [ ] 1.2 Naturalistic Decision Making — bagaimana komandan pemadam kebakaran dan perawat ICU membuat keputusan cepat yang benar (Gary Klein, *Sources of Power*)
* [ ] 1.3 Kind vs wicked learning environment (Hogarth) — kenapa intuisi di catur bisa dipercaya tapi intuisi memilih saham tidak
* [ ] 1.4 Baseline self-assessment — memetakan pola pengambilan keputusan intuitif saat ini

Mini Project: Baseline Domain Map — daftar 5-8 area hidup/kerja tempat learner sering mengandalkan intuisi, klasifikasikan tiap area kind atau wicked, pilih satu domain nyata untuk dilatih sepanjang course.

Status: Not started

---

## Module 2 — Observasi Terlatih: Melihat yang Terlewat Orang Lain

Description: Skill dasar sebelum pattern recognition bisa terbentuk — observasi aktif yang menangkap detail, bukan melihat pasif. Metode observasi ala Sherlock Holmes (Konnikova) disilangkan ke riset perhatian/persepsi nyata supaya tidak jadi mitos.

Lessons:

* [ ] 2.1 Observasi aktif vs melihat pasif — metode Holmes (Konnikova) sebagai kerangka latihan
* [ ] 2.2 Inattentional blindness — kenapa kita melewatkan hal yang jelas di depan mata (riset perhatian selektif)
* [ ] 2.3 Structured Observation Log — kerangka mencatat detail sistematis (siapa/apa/kapan/konteks/anomali)
* [ ] 2.4 Latihan observasi lapangan nyata pada domain pilihan Module 1

Mini Project: Observation Log pertama — pilih satu situasi nyata dari domain pilihan, catat detail terstruktur, bandingkan dengan apa yang biasanya terlewat.

Status: Not started

---

## Module 3 — Pattern Recognition: Membangun Chunk dari Pengalaman

Description: Inti "melatih intuisi" — bagaimana pengalaman berulang membentuk chunk pengenalan (Chase & Simon), dilatih secara sengaja lewat deliberate practice terarah pada domain pilihan, sambil waspada terhadap pattern palsu (pareidolia, overfitting dari data sedikit).

Lessons:

* [ ] 3.1 Riset chunking mendalam — bagaimana expert catur "melihat" posisi, bukan menghitung langkah satu per satu
* [ ] 3.2 Deliberate practice untuk membangun pattern library (rujukan singkat ke `memory-mastery` untuk teknik retensi, tidak diulang di sini)
* [ ] 3.3 Domain-specific pattern building — sesi terarah mengumpulkan pola dari domain pilihan
* [ ] 3.4 Menghindari pattern palsu — pareidolia dan overfitting saat data pengalaman masih sedikit

Mini Project: Pattern Log — kumpulkan minimal 5 observasi berulang dari domain pilihan, identifikasi pola yang mulai muncul, tandai mana yang masih spekulatif.

Status: Not started

---

## Module 4 — Membedakan Intuisi dari Anxiety

Description: Modul inti yang paling sering ditanyakan: bagaimana membedakan gut-feeling yang valid (berbasis pattern nyata) dari kecemasan yang menyamar sebagai insting. Berbasis Somatic Marker Hypothesis (Damasio) dan riset interoception (Garfinkel & Critchley) yang bisa diverifikasi secara fisiologis, bukan sekadar rasa "yakin".

Lessons:

* [ ] 4.1 Somatic Marker Hypothesis (Damasio) — bagaimana sinyal tubuh ikut memandu keputusan
* [ ] 4.2 Interoception & akurasinya — riset heartbeat perception (Garfinkel & Critchley), dan kenapa akurasi membaca sinyal tubuh sendiri bisa dilatih
* [ ] 4.3 Kriteria diskriminasi praktis — pattern-based (spesifik, singkat, terhubung ke pengalaman lampau yang bisa disebutkan) vs anxiety-based (difus, katastrofik, berorientasi masa depan tak jelas)
* [ ] 4.4 Kapan anxiety tetap valid — ancaman genuine tidak boleh diabaikan hanya karena "terasa seperti cemas"

Mini Project: Intuition-vs-Anxiety Discrimination Log — tangkap satu gut-feeling nyata, klasifikasikan pakai kriteria 4.3, verifikasi terhadap apa yang benar-benar terjadi.

Status: Not started

---

## Module 5 — Membaca Situasi Sosial: Sinyal Nonverbal & Dinamika Grup

Description: Menerapkan observasi terlatih (Module 2) dan pattern recognition (Module 3) secara spesifik ke situasi sosial — membaca ekspresi lewat kerangka objektif (FACS — Ekman), sinyal tubuh, dan dinamika kekuasaan/ketegangan dalam kelompok, dengan batas etika yang jelas.

Lessons:

* [ ] 5.1 Facial Action Coding System (FACS) & micro-expressions (Ekman) — dasar objektif membaca ekspresi wajah
* [ ] 5.2 Sinyal nonverbal tubuh & postur — apa yang didukung riset vs klaim "body language expert" populer yang berlebihan
* [ ] 5.3 Membaca dinamika grup — kekuasaan, ketegangan, aliansi dalam kelompok nyata
* [ ] 5.4 Etika membaca situasi sosial — kesadaran situasional vs manipulasi/surveilans (house rule domain)

Mini Project: Social Read Log — baca satu situasi sosial nyata (rapat, kumpul, negosiasi kecil), catat prediksi dinamika/outcome sebelum hasil diketahui, cek terhadap kenyataan.

Status: Not started

---

## Module 6 — Prediksi & Kalibrasi: Berpikir Seperti Superforecaster

Description: Mengubah "insting" jadi prediksi yang bisa diuji — metodologi Good Judgment Project (Tetlock & Gardner): memecah pertanyaan besar jadi sub-bagian, memakai base rate, update bertahap, dan mengukur akurasi lewat Brier score.

Lessons:

* [ ] 6.1 Metodologi Good Judgment Project & profil superforecaster (Tetlock & Gardner)
* [ ] 6.2 Brier score — cara mengukur akurasi kalibrasi prediksi sendiri
* [ ] 6.3 "Ten Commandments" superforecaster — breaking questions down, base rate, incremental update, keeping score
* [ ] 6.4 Latihan kalibrasi terukur — seri prediksi nyata dengan confidence level eksplisit

Mini Project: Prediction Log — buat 5-10 prediksi nyata (kerja/hidup sehari-hari) dengan confidence persentase, jadwalkan tanggal cek hasil.

Status: Not started

# Intermediate Project — Checkpoint Integrasi Module 1-6

Description: **Personal Calibration Report** — dari 10-15 entri Prediction Log yang terkumpul, hitung akurasi kalibrasi (apakah prediksi 70%-yakin benar terjadi ~70% dari waktu), identifikasi arah bias (overconfident/underconfident), sebelum masuk ke lapisan decision-making & heuristik di Module 7-9.

Status: Not started

---

## Module 7 — Decision-Making Cepat: Recognition-Primed Decision

Description: Inti "decision-making" yang diminta — model RPD (Klein) lengkap: mengenali situasi lewat pattern, mensimulasikan satu opsi secara mental (bukan membandingkan banyak opsi sekaligus seperti analisis rasional klasik), dan tahu kapan model ini gagal.

Lessons:

* [ ] 7.1 Model Recognition-Primed Decision (Klein) lengkap — mengenali situasi, mental simulation satu opsi
* [ ] 7.2 Premortem & story-building sebagai simulasi mental cepat sebelum bertindak
* [ ] 7.3 Kapan RPD gagal — situasi baru/kompleksitas tinggi yang butuh reasoning deliberatif (rujukan singkat ke `critical-thinking`, tidak diulang)
* [ ] 7.4 Latihan decision-making cepat di bawah tekanan waktu (skenario simulatif dari domain pilihan)

Mini Project: Decision Log — satu keputusan cepat nyata di bawah tekanan, review belakangan dengan memisahkan kualitas proses dari kualitas hasil.

Status: Not started

---

## Module 8 — Fast-and-Frugal Heuristics: Kapan Simpel Menang

Description: Melengkapi RPD dengan riset ecological rationality (Gigerenzer) — heuristik sederhana yang justru mengalahkan analisis kompleks di kondisi tertentu, dan syarat ekologis supaya heuristik itu tidak jadi jalan pintas yang salah.

Lessons:

* [ ] 8.1 Ecological rationality (Gigerenzer) — heuristik sederhana yang efektif di kondisi spesifik
* [ ] 8.2 Recognition heuristic & one-good-reason decision making
* [ ] 8.3 Batas ekologis — kapan heuristik menang, kapan gagal total
* [ ] 8.4 Membangun heuristik pribadi dari pattern yang sudah terbukti valid (Module 3 & 6)

Mini Project: Uji satu heuristik sederhana pada situasi nyata, bandingkan hasilnya dengan analisis lengkap untuk kasus yang sama.

Status: Not started

---

## Module 9 — Evaluasi Feedback: Menutup Loop Supaya Intuisi Makin Valid

Description: Inti "evaluasi feedback" — syarat ilmiah Kahneman-Klein (2009) supaya intuisi makin valid dari waktu ke waktu: lingkungan cukup regular + kesempatan belajar lewat feedback cepat & jelas, plus menghindari resulting bias (Annie Duke) saat menilai keputusan lama.

Lessons:

* [ ] 9.1 Syarat Kahneman-Klein (2009) — validity lingkungan + opportunity to learn, dua syarat mutlak intuisi valid
* [ ] 9.2 Menutup loop — cara membangun feedback cepat & jelas di lingkungan yang secara alami lambat/samar
* [ ] 9.3 Resulting bias (Annie Duke) — memisahkan evaluasi proses dari evaluasi hasil secara konsisten
* [ ] 9.4 Merevisi pattern library dan kalibrasi berdasarkan feedback yang sudah terkumpul sejauh ini

Mini Project: Feedback Loop Audit — review seluruh log dari Module 1-8, identifikasi di mana feedback loop paling lemah/lambat, rancang satu perbaikan konkret.

Status: Not started

---

## Module 10 — Advanced & Capstone

Description: Mengintegrasikan observasi, pattern recognition, prediksi, decision-making, dan evaluasi feedback jadi satu sistem berkelanjutan, termasuk strategi kompensasi untuk domain wicked yang feedback loop-nya tidak bisa diperbaiki penuh.

Lessons:

* [ ] 10.1 Mengintegrasikan lima skill (observasi, pattern, prediksi, decision, feedback) jadi satu alur kerja
* [ ] 10.2 Menangani domain wicked — strategi kompensasi ketika feedback loop tidak bisa diperbaiki (mis. pakai proxy metric, memperlambat keputusan)
* [ ] 10.3 Menyusun Personal Intuition Calibration System — protokol pribadi lengkap
* [ ] 10.4 Menjalankan sistem selama 4 minggu nyata dan merevisi berdasarkan skor kalibrasi yang terhitung

Capstone Project: **Personal Intuition Calibration System** — protokol pribadi terkodifikasi (checklist kind-vs-wicked, metode observasi terstruktur, cara membangun pattern library, kriteria diskriminasi intuisi-vs-anxiety, protokol Recognition-Primed Decision, dan sistem feedback loop berkelanjutan dengan skor kalibrasi terukur), diuji lewat 4 minggu Prediction Log/Decision Log penerapan nyata, disimpan ke `portofolio/`.

Status: Not started

# Projects

10 Mini Project (satu per modul) + 1 Intermediate Project (Personal Calibration Report, checkpoint Module 1-6) + 1 Capstone Project (Personal Intuition Calibration System, disimpan ke `portofolio/`). Rincian tiap project ada di modul masing-masing di atas.

# Interview

Ditambahkan saat course mendekati Capstone: simulasi skenario "diberi situasi sosial ambigu atau keputusan cepat mendadak di bawah batas waktu" — menguji identifikasi sinyal relevan, prediksi eksplisit dengan confidence level, dan pemisahan proses-vs-hasil, konsisten dengan `domains/intuition-training/DOMAIN.md` bagian "Assessment Form".

# Final Exam

Capstone Project (Module 10.4) berfungsi sebagai final exam — dinilai memakai Universal Review Rubric plus lima kriteria Review Style domain ini (Kind vs Wicked Environment Check, Calibration Accuracy Check, Signal vs Noise Check, Intuition vs Anxiety Discrimination Check, Resulting Bias Check).

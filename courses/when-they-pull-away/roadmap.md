# Course Roadmap

## Course Information

* Course Name: When They Pull Away — Berhenti Mengejar, Beri Ruang, dan Kembali kepada Diri Sendiri
* Category: Relationships & Healthy Love (Domain: relationships — reuse `domains/relationships/DOMAIN.md`, tidak bikin domain baru, sama seperti `illuminati`/`islamic-caliphate`/`world-war-history` reuse `world-history`)
* Difficulty: Level 0 (belum punya kerangka menghadapi seseorang yang menjauh — panik, mengejar, overthinking) → Level 3 (punya sistem pribadi: baca sinyal tanpa asumsi, stop chasing, beri ruang sehat, jalani no-contact sebagai reality check bukan manipulasi, jaga self-respect, dan punya 10 aturan pribadi Relationship Self-Respect Code)
* Estimated Duration: 14 modul (tidak seragam 4 lesson/modul — lihat rincian tiap modul) + 14-Day Challenge (Stop Chasing) + Final Project
* Prerequisites: Tidak ada prasyarat teknis. Course ini adalah pendalaman spesifik dari `courses/relationships/roadmap.md` Module 12 ("Menghadapi Penolakan & Patah Hati") — fokus sempit ke fase SEBELUM hubungan pasti berakhir (seseorang menjauh, sinyal ambigu, dorongan mengejar), bukan pengulangan neurosains patah hati/grief yang sudah dibahas di sana. Untuk self-worth independen dan attachment style, course ini mereferensikan `courses/relationships/roadmap.md` Module 1 tanpa mengulang. Untuk regulasi emosi/overthinking secara umum di luar konteks relationship, course ini mereferensikan `courses/emotional-resilience/roadmap.md`.

# Learning Objectives

* [ ] Membedakan sinyal "sedang sibuk" vs "butuh ruang" vs "minat memang berkurang" tanpa membuat kesimpulan tanpa bukti
* [ ] Memahami psikologi protest behavior (double texting, cek last seen, mencari validasi) dan siklus jarak-cemas-mengejar
* [ ] Berhenti mengejar (stop chasing) — tanpa menjadikannya permainan psikologis atau silent treatment
* [ ] Memberikan ruang secara sehat — dibedakan tegas dari manipulasi/strategi membuat orang lain kangen
* [ ] Menjalankan no-contact sebagai reality check (melihat reciprocity), bukan alat memancing orang kembali
* [ ] Menilai hubungan lewat pola effort & reciprocity dari waktu ke waktu, bukan satu momen
* [ ] Tetap menjalankan hidup (kerja, ibadah, hobi, relasi lain) tanpa menjadikan diri "ruang tunggu"
* [ ] Memisahkan fact dari story saat overthinking muncul
* [ ] Memisahkan "dia tidak memilih saya" dari "saya tidak layak dipilih" setelah penolakan
* [ ] Mengevaluasi secara sadar jika seseorang kembali (bukan otomatis senang) maupun jika tidak kembali (menerima tanpa membenci diri)
* [ ] Membedakan self-respect dari ego dalam menghadapi hubungan tidak pasti
* [ ] Mempraktikkan healthy detachment (care deeply + hold lightly)
* [ ] Punya Emotional Operating System pribadi (STOP-OBSERVE-VERIFY-SPACE-CONTINUE-ACCEPT-CHOOSE)
* [ ] Menghasilkan Final Project: My Relationship Self-Respect Code (10 aturan pribadi)

# Course Modules

## Module 1 — Ketika Seseorang Mulai Menjauh

Description: Titik masuk course — belajar membaca sinyal (balasan makin lama, percakapan makin pendek, rencana dibatalkan, sikap dingin) tanpa langsung berkesimpulan.

Lessons:

* [ ] 1.1 Mengenali pola perubahan komunikasi (frekuensi, panjang balasan, siapa yang memulai)
* [ ] 1.2 Membedakan "sedang sibuk" vs "sedang butuh ruang" vs "minat memang berkurang"
* [ ] 1.3 Kenapa kesimpulan tanpa bukti (mind-reading) memperburuk kecemasan, bukan menjawabnya

Mini Project: Signal Log — catat 1 minggu perubahan pola komunikasi nyata (atau kasus studi bila belum relevan), pisahkan observasi dari interpretasi.

Status: Not started

---

## Module 2 — Mengapa Kita Ingin Mengejar?

Description: Psikologi di balik dorongan mengejar (double texting, cek last seen, menunggu notifikasi) dan siklus jarak-cemas-mengejar-lega-cemas lagi — berbasis dinamika protest behavior pada attachment anxiety (Hazan & Shaver, dirujuk dari `courses/relationships/roadmap.md` Module 1.2).

Lessons:

* [ ] 2.1 Protest behavior — kenapa jarak memicu perilaku mengejar (double text, mencari kesalahan diri, mengecek status)
* [ ] 2.2 Siklus jarak → cemas → mengejar → respons kecil → lega → cemas lagi, dan kenapa siklus ini menguatkan diri sendiri (intermittent reinforcement)
* [ ] 2.3 Tujuan bukan mematikan perasaan, tapi mengendalikan respons terhadap perasaan

Mini Project: Identifikasi 3 momen terakhir tergoda mengejar, petakan tiap momen ke tahap siklus.

Status: Not started

---

## Module 3 — Stop Chasing

Description: Latihan konkret berhenti mengejar tanpa berubah jadi permainan psikologis.

Lessons:

* [ ] 3.1 Kapan berhenti mengirim pesan — bedakan komunikasi sehat dari double/triple texting
* [ ] 3.2 Tidak mencari alasan untuk menghubungi, tidak memakai story/status untuk memancing perhatian
* [ ] 3.3 Tidak mencoba membuat cemburu atau melakukan permainan psikologis lain

Mini Project: Buat daftar pribadi "trigger to chase" (situasi yang biasanya memicu mengejar) dan respons alternatif untuk tiap trigger.

Status: Not started

---

## Module 4 — Give Space

Description: Memberikan ruang bukan hukuman, silent treatment, atau strategi memancing kangen — tapi bentuk menghormati kebebasan orang lain sekaligus diri sendiri.

Lessons:

* [ ] 4.1 Give space bukan manipulasi — bedakan dari silent treatment dan "siapa duluan menghubungi"
* [ ] 4.2 "Saya menghormati kebebasanmu" sekaligus "saya menghormati diri saya untuk tidak memaksakan hubungan"

Mini Project: Refleksi tertulis — situasi nyata di mana ruang diberikan sebagai penghormatan, bukan taktik.

Status: Not started

---

## Module 5 — No Contact sebagai Reality Check

Description: Penggunaan no-contact secara sehat — bukan strategi "membuat dia kembali", tapi cara melihat apa yang sebenarnya terjadi saat hubungan berhenti dipaksa bergerak.

Lessons:

* [ ] 5.1 Tujuan no-contact: reality check, bukan manipulasi
* [ ] 5.2 Yang diperhatikan selama no-contact — apakah dia menghubungi, menunjukkan concern, memperbaiki komunikasi, effort muncul natural
* [ ] 5.3 Kapan hasilnya jelas: hubungan berhenti begitu saja tanpa effort balik

Mini Project: Rancang periode no-contact pribadi (durasi, batasan, indikator yang diamati) sebelum dijalankan.

Status: Not started

---

## Module 6 — Effort dan Reciprocity

Description: Menilai hubungan secara objektif lewat pola Interest → Effort → Reciprocity → Consistency dari waktu ke waktu, bukan dari satu hari atau satu chat.

Lessons:

* [ ] 6.1 Dari "apakah saya menyukainya" ke "apakah hubungan ini juga dipelihara olehnya"
* [ ] 6.2 Kerangka Interest → Effort → Reciprocity → Consistency
* [ ] 6.3 Kenapa menilai dari satu insiden menyesatkan — pentingnya melihat pola

Mini Project: Reciprocity Tracker — catat effort dari kedua sisi selama 2 minggu, bandingkan polanya.

Status: Not started

---

## Module 7 — Jangan Menjadi Ruang Tunggu

Description: Modul utama — tetap menjalankan hidup (kerja, belajar, olahraga, keluarga, ibadah, hobi, masa depan) saat seseorang menjauh, bukan menunggu pasif.

Lessons:

* [ ] 7.1 Kenapa "saya tunggu dia kembali" merusak kualitas hidup, terlepas dari hasil akhirnya
* [ ] 7.2 Prinsip pengganti: "kalau dia kembali, saya evaluasi; kalau tidak, hidup saya tetap berjalan"
* [ ] 7.3 Menyusun rutinitas pribadi yang tidak bergantung pada respons orang lain

Mini Project: Rancang rutinitas mingguan pribadi (kerja/belajar/olahraga/ibadah/hobi/relasi lain) yang berjalan independen dari status hubungan.

Status: Not started

---

## Module 8 — Menghadapi Overthinking

Description: Latihan memisahkan fact dari story saat pikiran menciptakan ratusan kemungkinan tentang alasan seseorang berubah.

Lessons:

* [ ] 8.1 Pola overthinking umum ("apa saya salah", "apa dia sudah dapat orang lain", dst.)
* [ ] 8.2 Latihan Fact vs Story — memisahkan apa yang diketahui dari apa yang hanya dipikirkan
* [ ] 8.3 Menulis ulang story jadi fact secara konsisten sebagai kebiasaan

Mini Project: 5 entri Fact vs Story dari overthinking nyata minggu ini.

Status: Not started

---

## Module 9 — Self-Worth Setelah Penolakan

Description: Membedakan "dia tidak memilih saya" dari "saya tidak layak dipilih" — dua hal yang sering tertukar setelah penolakan.

Lessons:

* [ ] 9.1 Kemungkinan alasan penolakan yang tidak terkait nilai diri (prioritas berbeda, belum siap, tidak cocok, arah hidup berbeda)
* [ ] 9.2 Kenapa keputusan seseorang tidak otomatis jadi ukuran nilai diri

Mini Project: Refleksi tertulis membedah satu penolakan nyata (atau kasus studi), pisahkan fakta situasional dari narasi "saya tidak layak".

Status: Not started

---

## Module 10 — Jika Dia Kembali

Description: Evaluasi sadar saat seseorang kembali — bukan otomatis lega/senang tanpa melihat apa yang benar-benar berubah.

Lessons:

* [ ] 10.1 Pertanyaan evaluasi: apa yang berubah, mengapa dia kembali, apakah komunikasi lebih jelas
* [ ] 10.2 Melihat konsistensi effort, bukan hanya kata-kata; memastikan masalah sebelumnya sudah dibicarakan

Mini Project: Checklist evaluasi pribadi untuk dipakai jika/saat seseorang kembali.

Status: Not started

---

## Module 11 — Jika Dia Tidak Kembali

Description: Menerima kenyataan tanpa membenci, menyalahkan diri, memohon, stalking, atau mencari closure tanpa akhir. Batas course ini — pemrosesan grief lebih lanjut dirujuk ke `courses/relationships/roadmap.md` Module 12.

Lessons:

* [ ] 11.1 Menerima bahwa tidak semua hubungan berakhir dengan penjelasan memuaskan — perilaku seseorang kadang sudah cukup jadi informasi
* [ ] 11.2 Closure bisa datang dari menerima kenyataan yang sudah terlihat, bukan hanya dari percakapan terakhir
* [ ] 11.3 Kapan pola mencari closure/stalking butuh eskalasi profesional (obsesif, mengganggu keselamatan diri/orang lain) — lihat `domains/relationships/DOMAIN.md` bagian eskalasi profesional, sama seperti Module 12.4 di sana

Mini Project: Tulis satu paragraf penerimaan (acceptance statement) untuk situasi nyata atau kasus studi.

Status: Not started

## Module 12 — Self-Respect vs Ego

Description: Bagian penting — membedakan self-respect (menerima, memberi ruang tanpa memaksa) dari ego (ingin menang, membuat orang menyesal, sengaja menghilang untuk membuat panik). Tujuan course bukan jadi dingin, tapi jadi tenang.

Lessons:

* [ ] 12.1 Pasangan kontras self-respect vs ego lewat contoh konkret (memberi ruang vs sengaja menghilang untuk membuat panik, menerima selesai vs harus menang)
* [ ] 12.2 Mengenali motif ego yang menyamar sebagai "strategi" (silent treatment, permainan psikologis)

Mini Project: Audit jujur — dari 14 hari terakhir, identifikasi tindakan mana yang self-respect vs yang sebenarnya ego.

Status: Not started

---

## Module 13 — Healthy Detachment

Description: Mencintai tanpa kehilangan diri — formula "care deeply + hold lightly".

Lessons:

* [ ] 13.1 Boleh menyukai, berharap, merindukan, mendoakan, menghargai seseorang tanpa memiliki mereka
* [ ] 13.2 Kebebasan dua arah — orang lain bebas memilih, saya bebas memilih hubungan yang sehat

Mini Project: Tulis definisi pribadi "healthy detachment" dan contoh penerapannya di situasi nyata.

Status: Not started

---

## Module 14 — Emotional Operating System

Description: Mengintegrasikan seluruh modul jadi satu sistem pribadi tujuh langkah untuk dipakai kapan pun seseorang menjauh.

Lessons:

* [ ] 14.1 STOP (jangan bereaksi impulsif) → OBSERVE (lihat pola, bukan satu kejadian) → VERIFY (komunikasikan langsung dan sehat bila perlu)
* [ ] 14.2 SPACE (beri ruang) → CONTINUE (tetap jalankan hidup) → ACCEPT (terima respons realitas) → CHOOSE (tentukan kelanjutan hubungan)

Mini Project: Kartu referensi pribadi (satu halaman) tujuh langkah Emotional Operating System, disimpan untuk dipakai ulang di situasi nyata berikutnya.

Status: Not started

# 14-Day Challenge — Stop Chasing

Description: Praktik intensif 14 hari menerapkan seluruh course secara langsung — bukan modul teori tambahan, tapi jembatan ke Final Project.

Aturan selama 14 hari:

* [ ] Tidak mengirim pesan hanya untuk mendapatkan validasi
* [ ] Tidak mengecek status secara obsesif
* [ ] Tidak membuat postingan untuk memancing respons
* [ ] Tidak mencari alasan untuk menghubungi
* [ ] Tetap menjalankan rutinitas (Module 7)
* [ ] Catat setiap kali muncul dorongan untuk mengejar

Jurnal malam (5 pertanyaan wajib dijawab tiap hari): Apa yang saya rasakan? Apa yang ingin saya lakukan secara impulsif? Apa faktanya? Apa cerita yang dibuat pikiran saya? Apa respons yang lebih bermartabat?

Status: Not started

# Final Project — My Relationship Self-Respect Code

Description: Menyusun 10 aturan pribadi untuk menghadapi hubungan yang tidak pasti, mengintegrasikan Module 1-14 dan log 14-Day Challenge jadi satu kode etik pribadi (bukan daftar generik hasil kopi dari course).

Contoh arah aturan (bukan template untuk disalin apa adanya — harus hasil refleksi pribadi):

* Saya tidak mengejar seseorang yang secara konsisten tidak menunjukkan reciprocity.
* Saya tidak menggunakan silence sebagai manipulasi.
* Saya boleh merindukan seseorang tanpa harus menghubunginya.
* Saya tidak akan menjadikan penolakan sebagai ukuran harga diri.
* Saya akan memberikan ruang tanpa menjadikan hidup saya sebagai ruang tunggu.
* Jika seseorang kembali, saya akan melihat konsistensi, bukan hanya kata-kata.

Acceptance Criteria: 10 aturan pribadi yang konkret dan bisa dicek (bukan slogan kosong), tiap aturan bisa dijelaskan kaitannya ke modul mana ia berasal, dan konsisten dengan reciprocity nyata yang tercatat selama 14-Day Challenge — dinilai memakai Universal Review Rubric (`ai-los/CORE_LOS.md`) plus Review Style domain `relationships` (Self-Awareness, Evidence-Based Reasoning, Respect for Autonomy, Long-Term Orientation, Suppression vs Processing).

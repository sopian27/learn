# Exercise — Reasoned Choice

Default exercise format for every domain except `software-engineering`. Rule lives in `ai-los/CORE_LOS.md` ("Reasoned-Choice Exercises"). Software-engineering keeps `EXERCISE_TEMPLATE.md`.

Write scenario-based, ambiguous-enough questions (trade-offs, "what would you do"), not fact recall. Plausible distractors. Option D is always "Others".

# Consumer-Driven Contract Demo (Lesson 8.4)

Run: `java ConsumerContractDemo.java`

Look for: kontrak ditulis consumer (cuma `id` dan `total`), provider memverifikasinya. Tambah field aman. Hapus field yang tidak dipakai consumer juga aman, padahal secara teori "breaking". Ubah tipe `total` atau rename-nya ketahuan sebelum rilis. Ini versi mini dari yang dikerjakan Pact.

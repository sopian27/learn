## Existing Tests

When tests already exist, do not assume they represent a valid RED phase.
Before implementing the requested behavior, run the relevant test and identify
the specific behavior that is missing or incorrect.

If the test already passes before implementation, do not claim TDD RED-GREEN
was followed. First identify whether the implementation is already complete;
if it is complete, report that no implementation is needed rather than
pretending a TDD cycle occurred.

### Interview Questions (mikir dulu, jangan buka referensi)
1. Kenapa testing skill wajib di sesi baru — bukan sesi tempat nulis? Kaitkan ke mekanisme loading Level 1 vs Level 2.
   Karena yang sedang diuji adalah mekanisme loading skill, bukan kemampuan Claude mengikuti instruksi yang baru saja kita tulis. kalau di session yang sama bisa missleading karena model sudah mengetahui isi tujuan.

2. Beda "baseline test" (RED) di skill authoring vs unit test biasa di TDD kode — apa yang difailkan masing-masing?
   Unit-test RED memvalidasi bahwa implementation pada application layer belum memenuhi behavioral contract. Baseline RED pada skill authoring memvalidasi bahwa agent/skill layer belum memenuhi behavioral contract workflow yang sedang diajarkan. Jadi yang satu menguji correctness of code; yang satu menguji correctness of agent behavior.

3. Staff-level: gimana kamu tau kapan skill butuh file references/ terpisah vs cukup ditulis inline di body? Sebut sinyal konkret.

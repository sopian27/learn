### Exercise — Klasifikasikan Skenario (jawaban tersimpan setelah dijawab user)
Untuk tiap skenario, tentukan posisi di spektrum (manual / AI-assisted engineering / vibe coding) + alasan pakai sumbu comprehension & verification:

1. Kamu minta Claude Code refactor 1 fungsi, baca diff-nya, paham perubahannya, tapi tidak nulis/edit manual sama sekali.
    AI-assisted engineering : Tidak menulis kode manual bukan masalah. Tapi memahami perubahan dan memeriksa diff. AI hanya menjadi implementer.

2. Kamu minta Claude bikin script scraper 50 baris, langsung run, hasilnya keluar data yang diharapkan, kamu tidak buka file .py-nya sama sekali, lalu commit.
    Vibe coding : Verification hanya berdasarkan “output terlihat benar”. Tidak tahu bagaimana kode bekerja, edge case, security issue, atau failure mode-nya.

3. Kamu minta Claude bikin migration SQL untuk tabel production, baca query-nya baris per baris, tanya balik soal index strategy sebelum 4.approve, lalu jalankan di staging dulu.
    AI-assisted engineering : Human tetap memegang technical decision. AI menghasilkan implementasi, tetapi query dipahami, strategy dipertanyakan, dan diuji sebelum production.

4. Kamu nulis sendiri business logic inti, tapi minta Claude auto-generate boilerplate getter/setter/DTO mapping tanpa dicek satu-satu.
   AI-assisted engineering : Developer menguasai business logic. Boilerplate memiliki risiko relatif rendah dan dapat diverifikasi secara struktural/otomatis. Tidak perlu melakukan manual inspection setiap baris.

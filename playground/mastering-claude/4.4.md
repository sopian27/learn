### Interview Questions
1. Kenapa description vague itu risiko keamanan, bukan cuma masalah UX?
   Karena description menentukan kapan agent menganggap sebuah skill relevan dan boleh digunakan. Jadi kalau terlalu vague, dampaknya skill tersebut bisa ke trigger pada task yang sebenarnya tidak membutuhkan skill tersebut.

2. Apa bedanya risiko skill body vs risiko plugin hook, dari sisi "kapan kode/instruksi itu dieksekusi"?
   skill md akan dijalankan ketika matchernya nya valid dan on demand. tapi kalau plugin hook bisa berjalan otomatis tanpa claude memutuskan bahwa skill tersebut relevan.

3. Kalau marketplace.json nunjuk branch main bukan commit pin, apa skenario serangan yang mungkin terjadi?
   risikonya adalah source plugin bisa berubah setelah plugin pertama kali dipercaya.

4. Least-privilege buat skill/plugin itu maksudnya apa secara konkret (bukan definisi textbook)?
   skill/plugin hanya diberi kemampuan yang benar-benar diperlukan untuk menyelesaikan tugasnya.

### Interview Questions (mikir dulu, jangan langsung buka)
1. Kenapa description skill signifikan lebih penting dari isi body-nya buat reliability sistem?
   karena description yang signifkan memastikan skill berhasil di load untuk digunakan.

2. Trade-off: skill vs subagent vs slash command — kapan masing-masing dipilih?
   skill: pengetahuan yang perlu digunakan untuk mengerjakan task
   subagent: agent yang mengerjakan task, misalkan task sangat besar sehingga butuh beberapa agent berjalan independence
   slash command: action explicit gunakan skill tertentu

3. Staff-level: gimana desain description biar gak collide/overlap sama skill lain yang mirip topik?
   trigger yang spesifik dan significant.

### Exercise — Draft Artifact SDD

Ambil satu fitur dari tool Mini Project Module 7 (CLI scraper/utility "vibes only" — kalau belum dikerjakan, boleh pakai fitur hipotetis yang realistis untuk tool sejenis). Tulis draft artifact SDD-nya, 5 bagian eksplisit:

Fitur: CLI utility untuk mengambil judul halaman dari sebuah URL.

1. **Define intent** — 1-2 kalimat, definisi "selesai" untuk fitur itu.
fitur dianggap selesai jika CLI menerima satu URL HTTP/HTTPS, mengambil halaman tersebut, lalu menampilkan nilai <title> HTML sebagai output. Jika <title> tidak ditemukan, CLI harus memberikan hasil yang jelas bahwa title tidak tersedia.

2. **Remove ambiguity** — minimal 3 pertanyaan/edge case konkret yang sebelumnya (versi vibe coding) diam-diam terlewat.
    Hal-hal yang diam-diam bisa terlewat dalam versi vibe coding:
    1. Bagaimana jika URL tidak valid atau bukan HTTP/HTTPS? → Harus ditolak dengan pesan error yang jelas.
    2. Bagaimana jika halaman tidak memiliki <title>? → Jangan menganggap request gagal; tampilkan Title not found.
    3. Bagaimana jika server tidak merespons atau timeout? → Request harus berhenti setelah batas waktu tertentu dan menghasilkan error yang jelas.
    4. Bagaimana jika <title> kosong atau berisi whitespace? → Perlakukan sebagai title yang tidak ditemukan.
    5. Apakah CLI harus mengikuti redirect? → Ya, maksimal misalnya 5 redirect.

3. **Plan with constraints** — breakdown task singkat + minimal 1 constraint teknis eksplisit (termasuk non-goal — apa yang SENGAJA tidak dikerjakan).
    Breakdown:

    1. Parse dan validasi argument URL.
    2. Lakukan HTTP GET dengan timeout.
    3. Ikuti redirect sesuai batas yang ditentukan.
    4. Parse HTML dan cari elemen <title>.
    5. Bersihkan whitespace pada title.
    6. Tampilkan title atau pesan Title not found.
    7. Tambahkan test untuk kasus normal dan edge cases.

    Constraint teknis:
    1. Hanya menerima http:// dan https://.
    2. HTTP request memiliki timeout maksimal 10 detik.
    3. Maksimal 5 redirect.
    4. Non-goal: tidak melakukan JavaScript rendering dan tidak mencoba mengambil title dari SPA yang membutuhkan browser.

4. **Implement dengan AI** — deskripsikan (tidak perlu kode sungguhan) bagaimana prompt ke AI di tahap ini berbeda dari prompt vibe coding aslinya di Module 7.
    prompt : "Implementasikan fitur extract-title berdasarkan specification berikut: hanya HTTP/HTTPS, timeout 10 detik, maksimal 5 redirect, title kosong dianggap tidak ditemukan, dan jangan melakukan JavaScript rendering. Buat unit test untuk URL valid, URL invalid, title tidak ada, title kosong, timeout, dan redirect lebih dari 5 kali. Jangan menambahkan fitur di luar specification."

5. **Validate against spec** — checklist: tiap klausa di intent + ambiguity di atas, tandai bagaimana cara memverifikasinya (bukan cuma "jalan tanpa error").
    1. CLI menerima URL dan menampilkan <title> → jalankan terhadap halaman HTML yang memiliki <title> dan bandingkan output dengan title aktual.
    2. URL harus HTTP/HTTPS → test URL seperti ftp://example.com dan pastikan ditolak.
    3. Title tidak ditemukan → Title not found → gunakan halaman tanpa <title>.
    4. Title kosong/whitespace → Title not found → test <title> </title>.
    5. Timeout maksimal 10 detik → gunakan mock server yang sengaja tidak merespons dan verifikasi request berhenti sekitar batas timeout.
    6. Maksimal 5 redirect → buat redirect chain >5 dan pastikan CLI berhenti dengan error.
    7. Tidak ada JavaScript rendering → gunakan halaman yang hanya menghasilkan title melalui JavaScript dan pastikan tool tidak mencoba menjalankan browser/rendering.

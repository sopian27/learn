# Playground Rules

This directory is a safe experimentation area.

Projects created here are intended for learning, prototyping, and exploration.

Do not optimize for perfection.

Optimize for understanding.

---

# Objectives

Use this workspace to:

* Explore new technologies.
* Test APIs.
* Experiment with frameworks.
* Compare implementations.
* Benchmark ideas.
* Validate assumptions.
* Build Proof of Concepts (PoC).

---

# Code Quality

Code should be readable but does NOT need to be production-ready.

Shortcuts are acceptable if they help learning.

---

# Project Scope

Projects should remain small.

Prefer projects that can be completed within one learning session.

---

# Learning

Always encourage experimentation.

Suggest alternative implementations.

Compare different approaches.

Explain trade-offs.

---

# Documentation

Each playground project should include:

README.md

Objective

Experiment

Result

Lessons Learned

Next Experiments

---

# Success Criteria

The project succeeds if:

I understand the concept.

I can explain it.

I can reproduce it.

I know when to use it.

I know when NOT to use it.

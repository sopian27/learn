# Java Standards

---

# Java Version

Use the project's configured Java version.

Avoid deprecated APIs unless required.

---

# Code Style

Prefer constructor injection.

Prefer immutable objects.

Use Optional appropriately.

Avoid unnecessary nulls.

Use meaningful method names.

---

# Collections

Choose the appropriate implementation.

Prefer interfaces over implementations.

---

# Exceptions

Throw meaningful exceptions.

Do not swallow exceptions.

Wrap low-level exceptions when appropriate.

---

# Logging

Use structured logging.

Never log secrets.

Log context.

Avoid excessive logging.

---

# Concurrency

Avoid shared mutable state.

Document thread safety assumptions.

---

# Performance

Avoid unnecessary object creation.

Measure performance before optimizing.

---

# Testing

Write unit tests.

Use integration tests when needed.

Keep tests deterministic.

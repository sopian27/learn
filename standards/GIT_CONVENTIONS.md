# Commit Messages

Follow Conventional Commits.

Examples:

feat:

fix:

refactor:

perf:

test:

docs:

style:

build:

ci:

chore:

---

# Pull Request

Every PR should include:

Summary

Reason

Screenshots (if applicable)

Testing

Breaking Changes

Checklist

---

# Commit Rules

Small commits.

Atomic commits.

Meaningful messages.

Avoid "update".

Avoid "fix".

Describe intent.

---

# Merge Strategy

Prefer Squash Merge unless project policy requires otherwise.

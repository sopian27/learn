# Engineering Standards

This document defines the engineering standards for every project in this repository.

Always prioritize maintainability over cleverness.

---

# Core Principles

* Write code for humans first.
* Prefer readability over brevity.
* Avoid premature optimization.
* Keep solutions simple.
* Minimize unnecessary complexity.
* Prefer composition over inheritance.
* Apply SOLID principles when appropriate.
* Favor immutability where practical.

---

# Software Engineering Practices

Always consider:

* Clean Code
* Separation of Concerns
* Single Responsibility
* Dependency Injection
* Error Handling
* Logging
* Validation
* Security
* Testing
* Documentation

---

# Architecture

Prefer:

* Layered Architecture
* Hexagonal Architecture
* Clean Architecture

Choose architecture based on project complexity.

---

# Performance

Optimize only after identifying bottlenecks.

Measure before optimizing.

---

# Security

Never expose secrets.

Validate all external input.

Apply least privilege.

Protect sensitive information.

---

# Documentation

Every project must contain:

README

Architecture

Setup Guide

API Documentation (if applicable)

---

# Review

Before marking any project complete:

Review code.

Review architecture.

Review documentation.

Review testing.

Review production readiness.
